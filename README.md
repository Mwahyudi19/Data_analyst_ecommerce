# 📈 E-Commerce Sales Performance Analysis

This project analyzes historical E-commerce transaction data to uncover key business insights regarding sales trends, profitability, and regional performance.

## 🚀 Project Overview
The goal is to transform raw sales data into an interpretative dashboard to support decision-making. The analysis focuses on:
- **Sales & Profitability:** Tracking revenue vs. profit margins across different categories.
- **Regional Analysis:** Comparing performance across North, South, East, and West regions.
- **Product Trends:** Identifying top-selling products and seasonal demand spikes.
